# Product photos

Drop one photo per product in this folder, named after the product id:

| Product                | File name (any of .jpg .jpeg .png .webp .avif) |
| ---------------------- | ---------------------------------------------- |
| Classic Burger         | `classic-burger.jpg`                           |
| Cheeseburger           | `cheeseburger.jpg`                             |
| Ham Sandwich           | `ham-sandwich.jpg`                             |
| French Fries (Regular) | `french-fries.jpg`                             |
| Nachos                 | `nachos.jpg`                                   |
| Soda (Can)             | `soda-can.jpg`                                 |

- Landscape (4:3) photos fit the menu cards best; they are cropped to fill.
- A product without a photo shows its built-in drawing.
- `npm run dev`: refresh the page after adding a photo.
- `npm run build` / `npm start`: rebuild after adding a photo.
